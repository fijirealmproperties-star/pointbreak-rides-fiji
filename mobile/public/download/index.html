Install Pointbreak on your Home Screen for quick access. It opens like an app and updates automatically.

  1. Tap Install now above (or the browser menu).
  2. Choose Install app / Add to Home screen.
  3. Launch it from your home screen like any app.
  1. Open this page in Safari (not inside another app).
  2. Tap Share (the square with the up arrow).
  3. Scroll down and tap Add to Home Screen.
  4. If it is missing, scroll to the bottom of the Share menu, tap Edit Actions, and enable it.
  5. Tap Add. If shown, leave Open as Web App turned on.

This creates a Pointbreak icon on your Home Screen; it does not install from the App Store.
