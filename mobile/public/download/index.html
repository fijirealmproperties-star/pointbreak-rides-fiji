Open in your phone browser first. You are inside another app (Facebook, Messenger, Instagram, etc.), which cannot install apps. Tap ⋮ / Share and choose Open in Chrome (Android) or Open in Safari (iPhone), or .
  1. Open this page in Chrome (or Samsung Internet / Edge).
  2. Tap Install app above, or the browser menu ⋮.
  3. Choose Install app / Add to Home screen.
  4. Launch it from your home screen like any app.
  1. Open this page in Safari (not inside another app).
  2. Tap Share (the square with the up arrow).
  3. Scroll down and tap Add to Home Screen.
  4. If it is missing, scroll to the bottom of the Share menu, tap Edit Actions, and enable it.
  5. Tap Add. If shown, leave Open as Web App turned on.
